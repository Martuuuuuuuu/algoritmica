## Descripción

Este repositorio corresponde a la Actividad 9 de Laboratorio de Programación, llamada "Pensar antes de programar".
El trabajo consiste en resolver diferentes problemas utilizando el razonamiento lógico antes de escribir el código. Para eso se trabaja con pseudocódigo, diagramas de flujo y pruebas de escritorio, que permiten organizar y comprobar los pasos de un algoritmo.

## Objetivos

- Aprender a analizar un problema antes de programar.
- Utilizar pseudocódigo para representar soluciones.
- Crear diagramas de flujo.
- Trabajar con variables y constantes.
- Aplicar condiciones y estructuras repetitivas.
- Realizar pruebas de escritorio para comprobar los resultados.
- Llevar los algoritmos a código utilizando C++.

## Contenidos

Durante esta actividad se trabajan los siguientes temas:
- Algoritmos y razonamiento lógico.
- Pseudocódigo.
- Diagramas de flujo.
- Variables y constantes.
- Estructuras condicionales.
- Estructuras repetitivas.
- Vectores.
- Pruebas de escritorio.
- Programación en C++.
